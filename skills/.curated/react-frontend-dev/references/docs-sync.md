# Tech Docs Sync

当功能、代码实现、页面结构、组件约束、交互行为、技术选型、框架配置或开发描述发生变化时，同步更新相关技术文档。

至少检查以下内容是否需要更新：

- 技术设计文档
- 前端开发规范
- 目录结构说明
- API 使用约定
- 组件使用说明
- 页面流程或交互说明
- monorepo 包职责说明

文档同步原则：

- 变更点在哪个层级发生，就更新哪个层级的文档
- 代码已改但文档仍描述旧行为时，以修正文档为默认动作
- 框架、脚手架、目录结构、provider 装配或基础设施配置调整后，必须同步更新 tech 文档
- 如果本次修改引入新的共享层、组件约束或交互规范，必须补充到文档中
- 文档内容应反映当前实现，不写空泛口号
