# 前端实现

用于页面、组件、请求、路由和状态变化；只核对受影响边界。改变用户任务或操作流程时读 [产品与交互](product-and-interaction.md)。

## 组件与归属

- 先查现有组件和数据层。点击、确认、取消等局部交互优先直接写在事件处理函数中，复用现有弹窗与提交状态；多个入口只共用文案时，复用常量即可。
- 页面负责路由和交互编排。只有已有重复的有状态逻辑、独立复杂状态或真实订阅生命周期时才抽 hook/composable；纯函数无需包装成 hook。防重、卸载保护或重试先检查现有机制，仅为具体缺口补充，不为包装一次调用增加层级。
- 业务组件接收内聚对象与意图回调；结构变化用组合/slot，有限模式用 variant，避免布尔参数组合出隐含状态机。
- 数据获取放在拥有完整请求生命周期的最近稳定边界。共享组件实现适用的状态、键盘、焦点与触控行为，不把页面请求细节塞进基础组件。

## 状态与请求

| 事实 | 所有者 |
| --- | --- |
| 可分享、刷新后决定结果的状态 | URL / 路由 |
| API 数据、请求、缓存、重试 | 项目统一服务端数据层 |
| 字段值、校验、dirty、提交 | 表单体系 |
| 瞬时交互 | 组件 / reducer |
| 真正跨页面且由客户端持有的状态 | 项目共享 store |

- 不将 query、props 或派生值复制成第二份权威状态。只在需要跨会话恢复时持久化，并处理版本、过期、退出清理和账号隔离。
- 请求复用项目鉴权、错误、取消和重试机制；进入、刷新或恢复页面时，将避免重复请求作为实现与验收要求，按下节统一请求生命周期。
- mutation 成功后按实体和查询范围更新/失效；乐观更新处理回滚、竞态和覆盖。提交成功后的缓存、关闭和导航顺序明确，失败保留可恢复输入。
- 集合按可靠上限、用户浏览和成本选择全量、分页、按需加载或聚合；前端切片不能降低无界请求的成本。可信业务事实及断链判定见 [跨层契约](cross-layer-contract.md)。

### 进入、刷新与请求去重

- **同一查询共享请求。** 同一缓存作用域内，语义相同的读取共享进行中的请求与结果；多个消费者、重渲染或重复生命周期回调不应各自发起请求。key 覆盖资源、有效参数及影响结果的账号/租户/权限作用域，使用一致的参数归一化；不能只按 URL 合并不同参数或身份。不为绕过缓存加入随机值或每次渲染的时间戳，原始凭证不进入 key。
- **先明确触发和归属。** 沿路由 loader/预取、挂载/显示、焦点/重连、参数恢复、失效与重试查调用链；让同一查询由统一数据层调度。依赖的路由参数、身份或筛选恢复完成后再启用请求，避免先用临时默认值请求、随即再拉真实条件；无依赖的查询仍可并行。
- **按机制选方案。** 优先复用现有 query/cache 或框架数据加载能力；需要共享缓存、并发去重和失效管理时采用适配技术栈的成熟方案。React 选型见 [React](frontend-react.md)；仅有 fetch/axios 封装不等于具备这些能力。简单孤立请求可保留最小实现，不为本要求强制迁移框架或引入第二套数据层。
- **去重与保鲜分别设计。** 进行中的请求合并，已完成的结果按业务可接受时效复用；明确过期、手动刷新、写入失效、焦点/重连及轮询策略。浏览器整页刷新通常会重建内存缓存，允许必要加载，要求消除该次启动中的冗余请求；不为追求跨刷新零请求默认增加持久化。
- **修复责任层。** 消除重复请求入口、缓存实例重建和不一致的查询定义；不要靠任意延时、全局锁、“只执行一次”标记或关闭生命周期检查遮住问题。取消/忽略旧响应用于资源清理和防止竞态，不能据此声称服务端没有收到重复请求。读取去重不替代写入操作的防重复提交与服务端幂等。

## 路由、权限与反馈

- 沿用项目路由定义和参数类型，校验/编码参数。新流程用 push，中间态替换用 replace，真实返回用 back，tab/根流程用平台 API。
- 深链、分享与冷启动不假设有历史栈；认证守卫保留合法目标、避免循环，区分未登录、无权限、不存在与不可见。
- 菜单、按钮和路由消费统一权限事实，服务端仍校验资源授权。身份切换后的会话与缓存重建见 [跨层契约](cross-layer-contract.md)。
- 字段错误靠近字段，页面错误与重试放稳定反馈区；服务端字段错误不能吞成泛化 toast。弹层处理焦点、键盘、关闭与遮罩行为。

## UI 与可访问性

- 沿用设计系统和平台习惯，让信息层级、主次动作、对齐和间距清楚；使用真实资产及有效点击区。
- 关键状态在稳定槽位内替换，避免重复内容与重叠点击区。持续输入期间，自动保存、同步等后台反馈的显隐、文案变化和换行不能改变输入区上方占用高度或推移光标/操作锚点；优先固定占位或有内容避让的覆盖，不靠延时掩盖跳动。主动展开、正文自然增长和必要内联错误可重排，保留焦点/滚动锚点，不为静态尺寸隐藏信息。
- 覆盖型操作由父容器提供定位上下文、内容避让和点击区；关闭按钮默认右上角，项目规范优先。
- 沿用目标视口、安全区和缩放规则，检查长文案与软键盘。优先原生语义、可访问名称、键盘顺序、焦点可见与对比度；沿用 i18n，尊重 reduced motion。
- 视觉值、字体组合与布局模式复用现有组件和语义 token；治理规则见 [Design token](frontend-design-token.md)。涉及 UI 质感、参考学习或视觉改进时读 [审美校准与验收](frontend-ui-quality.md)；规范合规与审美判断分别取证。

## 安全、性能与可靠性

- 不可信内容按文本渲染；原始 HTML 使用认可的 sanitizer。校验外链、重定向与上传边界，客户端不含秘密，敏感数据不进入 URL/日志或非必要持久化。
- 性能优化针对测得瓶颈；限制数据量后再判断虚拟化、懒加载和 memo。清理监听、定时器、订阅与未完成任务，媒体预留尺寸。
- 沿用项目 Error Boundary、错误页与上报，保留降级和重试并过滤敏感数据。

## 验证选择

遵循 [Development](../SKILL.md) 的验证范围。按行为选能发现错误的最小检查，不逐项穷举：

- 纯逻辑/状态转换：边界输入和不变量。
- 表单/共享组件：关键交互、失败恢复与可访问性；涉及输入期异步反馈时，在运行态连续输入并穿过保存/同步、成功、错误与恢复等受影响转换，核对输入区顶部/工具栏高度、焦点/选区和滚动锚点；窄视口与最长状态也要稳定，单张截图不能证明过程无跳动。
- 请求/缓存/路由：用 Network 的发起来源/时序或集成测试的真实请求计数，覆盖本次涉及的首次进入、整页刷新、返回/重挂载及多消费者；同 key 并发读取应合并，缓存仍新鲜且未显式刷新的重入不额外请求，变更有效参数/身份、手动刷新及写入失效仍应取得正确新数据。失败重试、轮询、预检和取消后重发分开解释，不能把所有网络记录机械断言为一次；仍需检查空/错与竞态恢复，不以 render 次数或 mock 掉数据层作为去重证据。
- 样式/响应式：在实际浏览器查看目标尺寸、真实数据密度、长中文、字体加载/回退下的布局、遮挡和位移；复用设计规则检查，纯样式不另造逻辑测试。相关状态按下一段选择，不为局部修复跑全套。
- 核心跨层流程/平台能力：定向集成、smoke 或 E2E；真实认证、回读和平台结果各自取证。

按受影响路径检查加载、空、错、无权限、键盘焦点与提交中/重复提交等状态；失败保留输入与恢复路径，写入防重与服务端幂等仍分别核对。用真实任务走查能否找到信息、完成主要动作并恢复失败；美感与取舍保留人工判断，不能由 lint 代替。

已有测试足够时复用；截图证明所示状态，差异大小不代表质量。视觉基线须来自已认可版本，参考图不能自动成为基线；不能为通过测试随意更新基线，先解释变化及对应任务/设计依据，沿用项目确认流程。交付说明实际检查的页面、尺寸、状态、结果和未验证范围；源码、lint 和构建通过不能宣称 UI 已验收，不自动扩大到其他平台或外部系统。
