# Frontend Admin Workspace

后台管理、运营工具、高频工作台、数据表和筛选分页改造时使用；营销页和普通内容页不读取。

## 信息架构

- 首屏直接进入列表、表单、详情或工作区；全局壳已提供导航时，不重复欢迎区、Hero、说明卡或无操作价值的大标题。
- Header、面包屑、标题、Tab、筛选和工具栏职责互补，合并无用途的重复；长内容或不同操作上下文需要重复动作时，保持同义、同状态和同结果。
- 稳定资源域用侧栏或二级导航；Tab 只切换同一任务内的视图或模式。入口按业务对象和高频任务组织，不按角色名称或后端表机械复制。
- 移除或合并入口前搜索深链、菜单、权限和跳转消费者；需要兼容时保留明确重定向。

## 壳层与控件

- 沿用项目共享壳、组件库和密度；页面级动作与标题同一行，返回属于左侧导航，提交属于右侧操作。
- 精确高度或宽度是外边框盒不变量；验收证据应包含 computed bounding box、固定区域与后续内容起点，不能只确认 CSS 中出现目标数值。
- 同一工具条或操作组的控件使用一致 size variant 和视觉节奏；短且互斥的固定集合可用 segmented，开放或较长集合用 select。
- 图标使用项目图标系统并提供可访问名称；纯图标按钮使用稳定点击区，不用字符或 Emoji 冒充图标。

## 列表与分页

- 无界或较大数据集由服务端筛选、排序和分页；明确有界的小集合可在客户端处理。查询状态进入 URL 或等价可恢复状态、query key 和请求参数；切换筛选或 page size 重置到有效页。
- 需要总数和跳页的分页器展示总记录数与当前 page size；允许调整时尊重用户选择。游标/连续加载使用真实可用的数量与继续加载语义，不为展示总数强行增加昂贵查询或伪造总数。
- 高频桌面工作台可让数据区占满剩余高度、独立滚动并保留表头与分页操作；内容页和窄屏可采用页面滚动。按任务与设备选择单一清楚的主要滚动区，避免嵌套滚动或遮挡最后一行。
- 不用 fixed 覆盖数据，不用假数据或任意 page size 制造整齐空白；每页数量由用户选择、产品约束和目标视口共同决定。

## 验证需求

- 覆盖有页面级动作和无动作页面、侧栏展开/折叠、菜单、账号区、常用与窄视口。
- 分别检查不足一页、恰好一页和超过一页；确认采用的总数/page size 或继续加载状态真实可见，表头、最后一行、分页器、筛选切换和 page size 请求一致且可到达。
- 记录关键外框和控件边界，比较切换前后是否对齐、换行、遮挡或跳动；单张成功态截图不能证明壳层完成。
