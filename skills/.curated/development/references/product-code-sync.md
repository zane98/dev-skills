# 产品-代码同构

当开发可能改变产品定义、业务规则、用户流程、权限、对外契约、数据语义、关键方案、架构边界、长期技术决策或产品/PRD 文档时，使用本协议。

只同步长期有效的事实与约束，不把文档写成 L3 修改日志。沿用仓库已有文档路径；新增明确、独立、需要长期维护的产品能力且没有等价 L2 时，创建最小文档和总图，小改动不搭建整套体系。

## 文档职责

- L1 `AGENTS.md`：记录 Agent 如何工作，包括开发规则、验证命令、长期架构边界、顶级职责和文档协议；不记录产品功能细节。
- L2 产品文档：记录产品预期事实与已选择的关键方案，包括目标、范围、流程、业务规则、状态、权限、关键契约、验收标准和 Code Map；不记录普通实现细节或变更历史。
- ADR/RFC/架构文档：沿用项目已有约定，记录长期技术决策的背景、备选方案、取舍、兼容迁移、发布和回滚；普通实现选择不新建决策文档体系。
- L3 代码/测试：实现并证明产品语义、架构边界和技术契约。

L2 只在以下情况更新：

- 产品预期事实、用户流程、业务规则、权限、状态、验收标准或对外契约变化。
- 新增、删除、重命名、拆分或合并明确且需要长期维护的产品能力。
- L2 已记录的关键方案、跨模块契约、Code Map 入口或职责发生变化。

仅移动内部模块职责、调整依赖方向或改变运行拓扑，但未改变产品语义且 L2 未记录相关方案/Code Map 时，不更新 L2；更新必要的 `AGENTS.md` 和 ADR/架构文档即可。

## 变化传播矩阵

| 变化 | L1 `AGENTS.md` | L2 总图 | L2 功能文档 | ADR/技术文档 | L3 代码/测试 |
| --- | --- | --- | --- | --- | --- |
| 新增/删除/重命名长期产品能力 | 通常不改 | 更新功能地图 | 新增、删除或改名 | 有长期技术决策时更新 | 实现并验证 |
| 修改产品流程、规则、权限、状态或验收 | 通常不改 | 功能边界变化时更新 | 更新对应事实 | 有关键取舍时更新 | 修改并按风险测试 |
| 修改对外契约或产品数据语义 | 边界变化时更新 | 功能边界变化时更新 | 更新契约、语义和验收 | 记录兼容、迁移和回滚 | 修改接口、数据与测试 |
| 修改内部模块边界、依赖方向、数据所有权或运行拓扑 | 更新长期约束 | 仅已登记入口变化时更新 | 仅产品语义或已记录方案/Code Map 变化时更新 | 更新决策与过渡方案 | 修改实现、迁移和边界测试 |
| 修改技术栈、运行命令、目录或文档协议 | 更新 | 仅产品文档入口变化时更新 | 通常不改 | 长期技术决策变化时更新 | 修改配置、脚本或代码 |
| 修 bug 以恢复既有定义 | 通常不改 | 不改 | 定义准确时不改 | 不改 | 修复并按风险补回归测试 |
| 内部重构、格式化、依赖小升级、无语义视觉微调 | 通常不改 | 不改 | 不改 | 通常不改 | 修改并做最小验证 |

## 判断顺序

1. 产品预期事实或验收是否改变？改变则更新对应 L2，并检查 L3。
2. 是否新增或改变独立、长期维护的产品能力？是则更新功能文档和 L2 总图。
3. L2 是否已经记录本次变化涉及的关键方案、跨模块契约、Code Map 入口或职责？已记录且发生变化才更新对应部分。
4. 是否改变长期架构边界、顶级职责、技术决策、运行命令或文档协议？是则更新 `AGENTS.md`，并按项目约定更新 ADR/技术文档。
5. 以上都否时，只修改 L3 代码/测试，不因代码变动补写 L1/L2。

## 修改 AGENTS.md

只写影响 Agent 工作方式的稳定约束：

- 开发流程、验证命令、必需工具和环境设置。
- 架构边界、顶级模块职责、依赖规则和仓库约定。
- 文档协议及产品/技术文档入口。

不要写入产品流程、业务规则、验收标准、完整 API 字段、页面实现或历史方案讨论。已有等价章节时修改原章节，不新增重复协议。

仓库需要最小协议时可写：

```md
## 文档同步

- `AGENTS.md` 记录开发规则、验证命令、架构边界和文档协议。
- 产品文档记录产品定义、已选择的关键方案、验收标准和 Code Map。
- 代码和测试实现并证明产品语义。
- 产品事实或已记录方案变化时同步产品文档；纯实现变化不触发。
```

## 完成条件

出现以下情况时，不要声称任务完成：

- 产品事实、验收或对外契约改变，但对应 L2 仍过期。
- 新增明确、长期维护的产品能力，却没有最小功能文档或总图登记。
- L2 已记录的关键方案/Code Map 改变，但文档未同步。
- 长期架构边界或技术决策改变，但 `AGENTS.md`、ADR、兼容迁移、发布或回滚说明仍过期。
- 文档变化后没有检查代码/测试，或文档与代码互相矛盾。
- `AGENTS.md` 包含本应放在产品文档的功能细节。
